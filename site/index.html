GPU Blueprint

What shader operations cost on each GPU architecture: the cost models SweetOpt uses to find faster shader code, measured on real cards.

1.0 = one fma (a fused multiply-add at full rate), measured as throughput: many independent operations in parallel. Lower is better. Numbers are rounded to what the cost models use.

Cards measured

Every report comes from GPU Blueprint's OpBench run by a volunteer. Cards of the same architecture measure alike, so they share one cost model.

Pixel shader order

How each GPU hands pixels to its shader cores: TexBench numbers every pixel of a full-screen draw in the order it ran. The colour runs from first (blue) to last (red); the close-up shows the blocks of pixels shaded together.

Measure your card: download GPU Blueprint from the releases page, run it and send the reports from its menu. Only the card, its driver version and the measurements are published.
