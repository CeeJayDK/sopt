Test Host

ReShade on every graphics API, without a game: Direct3D 9, 10, 11 and 12, Vulkan and OpenGL. A window shows a fixed test image (and a depth buffer, like a game's) with ReShade in front of it, so effects can be tested, compared across APIs and benchmarked.

How to use

  1. Extract this zip into a folder.
  2. Double-click Test-Host.bat and press a number.
  3. Results (screenshots, ReShade's logs and a zip of them) go to the Results folder.

Nothing outside this folder is touched: the runs use their own folder (run\) with their own ReShade.ini; no ReShade installation and no game. ReShade 6.8.0 with add-on support is included.

The menu

1IEEE 754 test on every API. Runs sopt_IEEE754.fx on each API and takes a screenshot of it (about 2 minutes). Send the zip from the Results folder.
2The same on one API you pick.
3Your own effect on every API. Pick an effect from the Effects folder; every technique in it is switched on and each API gets a screenshot. If an effect does not compile on an API, the summary says so and ReShade's log for that API is in the results.
4Open the test host with ReShade on an API you pick and try effects by hand: press Home in the window for ReShade's overlay. Your effect choices are kept between runs. The sopt-timer add-on shows each technique's GPU time in the overlay's add-on tab.
5Benchmark a SweetOpt test package: extract the sopt-compare-*.zip into this folder first. Every original / variant pair is timed on the GPU (Direct3D 11 and Vulkan), with a screenshot per preset.
6 / 7Open the Results / Effects folder.

The IEEE 754 test

62 rules for float math (NaN, infinity, signed zero, rounding, conversions), each checked three ways:

Foldedfrom literals only: the compiler works the answer out
LiteralNaN, infinity or -0 written into the shader code as a literal and used on the GPU
Run timemade on the GPU, so nothing can be worked out in advance

ok = as IEEE 754 and HLSL require, FAIL = wrong, D3D = differs from Direct3D's rule (Vulkan and OpenGL leave the result to the driver there), yes / no = either is allowed. The title line names the API and the ReShade version. What it found so far is in Docs\IEEE754.md. Direct3D 9 shows only the run-time column, one box per test (it has no NaN / infinity literals and no integer operations for the text).

Your own effects

Put .fx files (and the headers and textures they use) into the Effects folder; subfolders are searched too, so a whole reshade-shaders folder can go there.

Options

From a command prompt in the bin folder:

powershell -File run-test.ps1 -Apis dx11,vulkan -Effect MyEffect.fxa test on some APIs (dx9, dx10, dx11, dx12, vulkan, gl or all); -Width / -Height (default 1920 x 1080), -Frames (frames with the effect before the screenshot, default 30)
powershell -File run-test.ps1 -Apis dx12 -Interactivethe host with ReShade, by hand
powershell -File run-bench.ps1 -Apis dx11 -Frames 600 -Width 2560 -Height 1440the benchmark with other settings
-ReShade path\ReShade64.dllanother ReShade (with full add-on support); a ReShade64.dll or ReShade_Setup_*_Addon.exe next to Test-Host.bat is used too

What is in the bin folder

sopt-host.exethe test window: a fixed test image and a synthetic depth buffer, vsync off, on any of the six APIs (--api dx9|dx10|dx11|dx12|vulkan|gl)
sopt-timer.addon64 / .addon32the ReShade add-on that times techniques, runs the benchmark and takes the test screenshots
run-test.ps1, run-bench.ps1, common.ps1the scripts behind the menu
sopt-fxc.exeMicrosoft's fxc -O3 on one HLSL entry point (for sopt-fx --backends)
timings.pymerges several benchmark CSVs into one table
ReShade64.dllReShade 6.8.0 with full add-on support, built unchanged from crosire's source (license in Docs\ReShade-LICENSE.md)
