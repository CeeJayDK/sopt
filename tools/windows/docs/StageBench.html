GPU Blueprint / StageBench

StageBench

What math costs in pixel and vertex shaders, the kinds of shaders ReShade effects run.

How to run

From the GPU Blueprint menu (GPU-Blueprint.bat): 1 to 3 run it with the other programs, S alone. It takes about half a minute to a minute and a half (up to 5 on old cards) and writes Reports\stagebench-ps-<GPU>.csv and Reports\stagebench-vs-<GPU>.csv.

Command line

--stage ps, --stage vsonly the pixel or only the vertex shader run (without it: both, one after the other)
--list, --adapter N, --filter textas in OpBench

Why

OpBench measures in a compute shader. ReShade effects are mostly pixel shaders, and a graphics driver does not always treat the kinds of shaders alike. On a GTX 1660, for example, half precision math is twice as fast in a compute shader, but no faster in a pixel or vertex shader, while an RTX 2060 or 2070 gets the gain in all of them. StageBench finds such differences, so SweetOpt can use the costs of the kind of shader it is optimizing.

How a test works

StageBench is OpBench's own program with the same tests and the same units (one fma = 4 units), run in two other places:

Pixel shader psone thread per pixel of a 1024 x 1024 image. This run also has the tests only pixel shaders can do: ddx / ddy (how a value changes to the next pixel) and clip.
Vertex shader vsone thread per point, drawn off-screen.

Only the "many in parallel" way of running (tput) is measured: what an instruction costs when the GPU is fully busy, as in a game. Tests that only exist in compute shaders (shared memory, barriers, atomics) are left out. Everything else, from the reference checks before every test to the forward and backward passes and the extra readings when two disagree, works as in OpBench.

Reading the CSVs

Each file is laid out like OpBench's CSV (see OpBench), with one more # line: stage: ps or stage: vs. The expected column compares your card with other cards of its family in the same kind of shader.

Compared with compute shaders

The StageBench page on the SweetOpt site puts each card's pixel and vertex shader costs next to its compute shader costs from OpBench and marks where they differ.

StageBench writes only Reports\stagebench-ps-<GPU>.csv, Reports\stagebench-vs-<GPU>.csv and the tests' shaders in Reports\Shaders\StageBench-ps\ and -vs\. It does not use the network. Part of sopt by CeeJay.dk (GPL-3.0).
