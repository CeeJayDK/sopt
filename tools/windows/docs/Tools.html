SweetOpt bench tools

Measures the real speed of SweetOpt's variants: every original / variant pair of a test package, timed on the GPU in ReShade, on DX11 and Vulkan.

How to run

  1. Extract this zip into a folder.
  2. Extract the test package (sopt-compare-*.zip: a folder with sopt-presets\ and reshade-shaders\) into the same folder.
  3. Double-click run-bench.bat. A 4K window opens and closes by itself, first for DX11, then for Vulkan; each preset warms up, is timed for 300 frames and gets a screenshot.
  4. Send the results-<date>.zip it writes next to run-bench.bat: the timings per API, the screenshots (the presets end in a Compare effect, so a black image means the original and the variant look the same), ReShade's logs and the GPU name.

Nothing outside this folder is touched: the run uses its own folder (run\) with its own ReShade.ini, no ReShade installation and no game.

Options

From a command prompt: run-bench.bat -Apis dx11 -Frames 600 -Width 2560 -Height 1440.

-Apisdx11, vulkan or both (default)
-Framesframes timed per preset (default 300)
-Width, -Heightwindow size (default 3840 x 2160)
-ReShadeanother ReShade64.dll (with full add-on support); a ReShade64.dll or ReShade_Setup_*_Addon.exe next to run-bench.bat is used too
-Packagethe test package folder, if it is somewhere else

What is in the bin folder

sopt-host.exea window with a fixed test image and a synthetic depth buffer, vsync off (DX11 or Vulkan)
sopt-timer.addon64 / .addon32the ReShade add-on that times the techniques and runs the bench
run-bench.ps1the bench script run-bench.bat starts
sopt-fxc.exeMicrosoft's fxc -O3 on one HLSL entry point (for sopt-fx --backends)
timings.pymerges several timing CSVs into one table
ReShade64.dllReShade 6.8.0 with full add-on support, built unchanged from crosire's source (license in Docs\ReShade-LICENSE.md)

To measure what a graphics card's instructions and textures cost, use GPU Blueprint (its own download).
