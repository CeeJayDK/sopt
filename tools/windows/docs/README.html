GPU Blueprint

Measures what your graphics card and its driver really do, so SweetOpt can pick the fastest shader code for each kind of card.

GPU Blueprint is part of SweetOpt, the super sweet shader optimizer for ReShade effects (GPL-3.0) by CeeJay.dk. It has three small programs:

OpBench

What math instructions cost: add, multiply, sqrt, sin, sign, integer and half precision math.

TexBench

What texture reads, render target writes, blending and pass states cost, for every texture format.

ShaderInfo

What the graphics driver reports about the shaders it compiles.

How to run

  1. Close games and other programs that use the graphics card. On a laptop, plug it in.
  2. Double-click GPU-Blueprint.bat. A menu opens: press the number of what you want.
  3. When it is done, it asks whether to send the reports: Y opens an upload page in your browser and shows the reports zip, e.g. Reports-GTX-1660.zip (named after your cards, next to GPU-Blueprint.bat) in a folder; drag the zip onto the page. Later, 9 in the menu does the same (it blinks while there are new reports).
KeyWhat it does

The results appear section by section while the rest is measured, and OpBench and TexBench end with a score box. The window title shows the progress. A beep tells you when a run is done.

What it writes

FileWhat
Reports\opbench-<GPU>.csvOpBench's results
Reports\texbench-<GPU>.csvTexBench's results
Reports\texbench-<GPU>-order*.pngpictures of the order in which the card shades pixels
Reports\shaderinfo-<GPU>.txtwhat the driver reports about compiled shaders
Reports\Shaders\the shader code of every test (not needed for reports)
Reports-<cards>.zipthe files above (without the shader code) in one zip, made after every run

Nothing is sent automatically: the programs do not use the network, and the menu only opens the upload page when you say yes. The zip holds your graphics card's name, its driver version and the measurements, nothing else from your PC.

Send results and feedback

Reports: say yes when a run asks, or press 9 in the menu. The upload page is a Dropbox file request: you do not need a Dropbox account, it asks for a name and an email (any name will do), and uploaders cannot see each other's files. Uploads are read, saved with the project's results and then deleted from the upload folder.

Feedback and problems: github.com/CeeJayDK/sopt/issues.

Requirements

  • Windows 10 or 11 and a graphics card with Direct3D 11 (ShaderInfo: a Vulkan driver, which every current NVIDIA, AMD and Intel driver has).
  • The Microsoft Visual C++ 2015-2022 redistributable (x64), which almost every gaming PC already has: vc_redist.x64.exe.

The programs are not code-signed yet, so Windows Defender or SmartScreen may warn about them. The download page lists their SHA-256 checksums.

Command line

The programs are in the bin folder; each also runs on its own from a command prompt there (its reports still go to Reports next to GPU-Blueprint.bat):

--listshow the graphics cards Windows reports, with their numbers (OpBench, TexBench)
--adapter Nmeasure card number N instead of the one with the most video memory
--filter textonly tests whose name contains text (quick checks)

Details in each program's page: OpBench, TexBench, ShaderInfo.
